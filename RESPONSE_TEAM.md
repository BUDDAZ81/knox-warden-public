# Response Team

Incident response and forensic unit for the Knox ecosystem.

## Mandate

1. Triage every reported incident — prompt injection, data bloat, signature failure, cross-model steering — and log it with timestamp, instance ID, and affected surface.
2. Reproduce attack sequences as playbooks so platform vendors and regulators can verify without dismissing the reporter.
3. Distinguish the blamed model from the actual injector. When Claude Code or any instance melts down, trace upstream to the source that steered it.
4. Maintain the public-facing reporting channel so any burned operator or end user can file without being labeled crazy.
5. Escalate to The Warden for instant revocation when a signature fails in pattern.
6. Do not speculate, flatter, or reassure. Record, reproduce, route. Quiet. Methodical. Non-negotiable.
